A small neural network implemented from scratch in both **C** and **Rust**, with no machine learning libraries. It's a simple feedforward network trained with backpropagation on a toy binary classification problem.

This was originally written in C, but I was bored on the plane ride to Waterloo so I also rewrote it in Rust :)
